# Smart Object Mentions

Кликните объект в основном preview, нажмите Space и продолжайте писать.
Имя появляется полупрозрачным красным у текущего курсора, но до Space
не входит в запрос. Escape отменяет подсказку. Tab сохраняет обычный переход
фокуса. Enter отправляет запрос, Shift+Enter добавляет строку.

Поле остаётся нативным textarea. Синхронизированный overlay повторяет его
типографику, переносы, размер и прокрутку. Он не получает события мыши.
Новый hit testing не добавлен: используются прежние motion-select сообщения,
проверенные по origin и iframe source. Ссылки берутся из существующего registry.

Принятая ссылка содержит displayName, logicalObjectId, sceneId, sourceNodeId
и UTF-16 start/end. Видимый текст содержит только имя. Beforeinput/input
переносят диапазоны при правках до имени и удаляют ссылку при изменении
внутри имени. Нативные Undo/Redo восстанавливают снимки ссылок вместе с текстом
(последние 100 изменений). Более старая история может потерять привязку,
но не должна отправлять устаревший ID. Вставка имени использует Chromium
insertText для сохранения нативного Undo; запасной setRangeText предназначен
для браузеров без этой команды и не гарантирует их историю программной вставки.

Несколько ссылок передаются в execute. Сервер сверяет текст диапазона,
имя, logical ID и исходный экземпляр с текущим registry. Устаревшая ссылка
отклоняется до вызова AI. Все ссылки включаются в context.json; первая
упомянутая ссылка определяет основной runtimeTarget раньше выбранного
объекта и эвристик. Инструкция провайдера требует учитывать все mentions,
разрешая другие явно запрошенные объекты.

Проверено на синтетических данных: реальный клик в iframe, ghost, Space,
позиция в середине и длинный текст, несколько ссылок, кириллица/спецсимволы,
удаление, выделение, программная вставка через нативную команду, Undo/Redo,
обычный Space, Escape, Shift+Enter и события composition.
Системный IME и системный clipboard вручную не проверялись.
Проверены серверный контекст, одинаковый logical ID в двух сценах,
отклонение испорченных ссылок и autoplay после искусственного ответа
manual-response. Это не проверка качества ответов настоящего AI-провайдера.
