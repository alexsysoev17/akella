# Motion timing
Recommendations only; current parameters and latest instructions take precedence.
Use actual project FPS and global frames. Duration changes perceived speed while easing redistributes it. Very slow beginning/end with a sharp middle suggests a cubic Bezier with high x1 and low x2, e.g. .85,0,.15,1. More dramatic middle: move x1 toward 1 and x2 toward 0, preserving endpoints. To soften stopping, flatten the end tangent or use Hermite with terminal slope zero. Sample incoming velocity from the base track for inertial follow-through; do not invent it. An exactly settled base has little instantaneous velocity. Raw new inertialOvershoot uses the common core instantaneous derivative; tuneInertia uses endpointExact for its matched response. No AE wording or mode selection is needed from the user. Explicit AE Easy Ease uses `aeEasyEase` with zero endpoint speed and 33.33% influence, and inertia uses `parameters.mode="ae"`: sample the eased BASE derivative at keyTime-frameDuration/10 with a small subframe step. Endpoint sampling preserves the literal AE formula. Explicit velocitySampling=lookback is a different momentum-window model: use only deliberately, measure continuity at the base/tail join and disclose that choice; never invent an impulse. Saved legacy inertia retains its documented secant window and smooth settling. AE mode preserves the literal duration cutoff unless smoothTail is explicitly selected. Reserve frames after the base movement for inertia and for the final settled frame. Frequency uses Hz and decay uses inverse seconds for new expressions, unlike legacy cycles-per-duration effects.

For smooth artistic follow-through use tuneInertia (motion-guidelines): an explicit matched approach plus velocitySampling=endpointExact and an effective tail coefficient 1/(2*pi*frequency) gives C1 base/tail continuity. In coupled mode the evaluator supplies that coefficient; the stored amplitude controls approach strength. This is distinct from literal AE sampling at endpoint minus 0.1 frame. Preserve an explicitly fixed curve with approach=preserve; adapt only when changing the approach is allowed. Frequency/decay affect the required approach velocity for a requested displacement. Always measure the actual result.

C2 coupled update: tuneInertia adapt now also matches initial tail acceleration (-2*decay*velocity). It checks the braking interval, not only the endpoint. For its linked responseMode=coupled, amplitude is an artistic control applied to approach strength; frequency and decay edits refit too. Legacy unlinked formulas keep their old coefficient semantics. Preserve mode does not promise acceleration continuity.

For a new suitable single movement from rest, the approved whole-approach method is tuneInertia approach=continuous; read inertia-continuity. It matches scalar velocity/acceleration/jerk and continues the complete moving pose. It does not preserve a literal original easing, and its numeric settings must be chosen for the current geometry and timing.
