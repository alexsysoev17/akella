# Motion timing
Recommendations only; current parameters and latest instructions take precedence.
Use actual project FPS and global frames. Duration changes perceived speed while easing redistributes it. Very slow beginning/end with a sharp middle suggests a cubic Bezier with high x1 and low x2, e.g. .85,0,.15,1. More dramatic middle: move x1 toward 1 and x2 toward 0, preserving endpoints. To soften stopping, flatten the end tangent or use Hermite with terminal slope zero. Sample incoming velocity from the base track for inertial follow-through; do not invent it. An exactly settled base has little instantaneous velocity. All NEW inertialOvershoot uses the common core instantaneous derivative; no AE wording or mode selection is needed. Explicit AE Easy Ease uses `aeEasyEase` with zero endpoint speed and 33.33% influence, and inertia uses `parameters.mode="ae"`: sample the eased BASE derivative at keyTime-frameDuration/10 with a small subframe step. Endpoint sampling preserves the literal AE formula. Explicit velocitySampling=lookback is a different momentum-window model: use only deliberately, measure continuity at the base/tail join and disclose that choice; never invent an impulse. Saved legacy inertia retains its documented secant window and smooth settling. AE mode preserves the literal duration cutoff unless smoothTail is explicitly selected. Reserve frames after the base movement for inertia and for the final settled frame. Frequency uses Hz and decay uses inverse seconds for new expressions, unlike legacy cycles-per-duration effects.
