# Kinetic typography
Recommendations only: explicit user direction wins.
Protect headline hierarchy and time to read. A restrained translation/fade or scale often works better than several competing effects. Native TEXT supports compact animation.text settings: segmentation block/line/word/character, timing simultaneous/staggered/sequential, staggerFrames, reverse, origin local/outsideViewport/masked. The loaded, shaped source is measured once; SVG slices preserve style runs and final source layout. Use identical settings for Slide+Fade, never one persisted track per character. Total track duration includes stagger. Update existing tracks for faster text; segmentation=block removes slices without deleting text or block effects. Character clipping does not guarantee exact independent ligatures/complex scripts; do not claim that capability. Hold important messages before the exit. Large overshoot can briefly reduce readability; the user can intentionally request this. Typography remains structured source content; animate container transforms without replacing text with pixels.

Slide Up + Fade + Overshoot changes position and opacity only; it must not add text clipping. Use explicit `maskReveal` only when the user requests a mask reveal. It clips an effect wrapper from measured source and loaded text line boxes and removes its clip at progress 1; source Frame clipping and Figma masks remain active. Never copy font aliases between different scenes.
